# User Registration Form (JavaScript)

## 📌 Project Description
This project is a User Registration Form built using HTML, CSS, and JavaScript with strong validation and user feedback.

The project is implemented in two phases:
- Phase 1: JavaScript Function Prototypes
- Phase 2: ES6 Classes and Objects (Refactored Version)

## 🎯 Objectives
- Build a registration form with validation
- Implement validation using function prototypes
- Refactor code using ES6 classes
- Provide proper error handling and user feedback

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript (ES5 & ES6)

## ✨ Features
- Name validation (cannot be empty)
- Email format validation
- Password length validation
- Error messages for invalid input
- Success message on valid submission
- Clean and responsive UI

## 📚 Project Phases

### 🔹 Phase 1: Function Prototypes
- Used constructor functions
- Prototype methods for validation logic
- Traditional JavaScript approach

File Used:
- script-prototype.js

### 🔹 Phase 2: ES6 Classes (Refactored)
- Converted prototype logic into ES6 class
- Improved readability and maintainability
- Modern JavaScript practices

File Used:
- script-class.js

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open the project folder
3. Open index.html in any browser
4. Fill the form and test validation
